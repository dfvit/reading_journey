Sync with GitHub

Saves your added books, read ticks and plan to reading-data.json in your repo, so every device shows the same list.

Create a token at GitHub → Settings → Developer settings → Fine-grained tokens. Select only this repo and give it Contents: Read and write. It is stored only in this browser, never in the page. Note: if the repo is public, your list is public too.
Tick a book to mark it read, add new books any time, then hit Re-plan to move finished books out of the way. Everything is saved in your browser.
